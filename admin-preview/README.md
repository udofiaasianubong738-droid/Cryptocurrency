# CryptoInvest Admin — public interface preview

This folder is a static, navigable design preview only.

## Safety boundaries
- No real customer data, fabricated metrics, passwords, MFA codes, service-role keys, or secrets are included.
- No live administrator authentication is provided on GitHub Pages.
- Backend data remains unavailable until the separate secured admin application enforces CEO authorization, AAL2, server-side checks and Supabase RLS.
- Financial operations remain disabled. This preview cannot initiate or approve deposits, withdrawals, payouts, transfers or investment transactions.

## Preview screens
Welcome, identity verification, overview, customer directory, customer profile, investment records, performance reports, documents, notifications, AI operations, security centre, audit logs, settings and help/support.

## Local preview
Open `index.html` in a browser, or serve this folder with any static file server. The navigation is hash-based and all preview controls either navigate or explain the unavailable backend action.

## GitHub Pages
The repository workflow publishes this folder as the public interface preview after a verified merge to `main`. Never add credentials or customer information to this folder.
